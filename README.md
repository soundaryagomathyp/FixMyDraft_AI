# 🛡️ FixMyDraft_AI

### Every Draft. On Brand. Every Time.

An intelligent brand governance platform that checks content before publication.

## Features
- Brand profile management
- PDF guideline extraction
- Draft submission
- Automated brand compliance checking
- Avoided word detection
- Missing approved terminology detection
- Unsupported claim detection
- Correction suggestions
- Evidence-linked explanations
- Downloadable PDF compliance reports

## Technologies Used
- Python
- Streamlit
- pypdf
- ReportLab
- Regular Expressions

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
